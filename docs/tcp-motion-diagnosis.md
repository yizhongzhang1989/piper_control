# TCP 运动卡顿排查（进行中）

2026-11-26，真机 `arm_2 / can1`，API 8090。当前尚未达到 TCP 直线和圆弧
全程顺滑的验收要求。此前接口验收只证明功能执行和终点到位，不能证明路径速度平顺。

## 已确认并修复的软件问题

1. 连续 TCP 逆解采用的收敛容差过粗。在平滑起步和停车处，相邻路径点小于原容差，
   逆解会提前返回旧关节角，产生平台和速度脉冲。现在统一收紧原生和备用逆解的容差。
2. 原轨迹使用差分关节速度重建 Hermite 样条，采样点处加速度不连续。现在用同一条
   端点零速度的 C2 样条求导，保证内部节点加速度连续。
3. 圆弧经过中间姿态时，分段 Slerp 可突然改变角速度方向。现在使用旋转样条连续通过
   中间姿态，并按该曲线的角速度估算自动运动时间。
4. 控制器反馈暂时过期或发生控制异常时，会丢弃保持目标，恢复反馈后改用测量位置。
   这会把原跟踪误差变成目标跳变。现在保留原目标，中止原任务，恢复后保持原目标。
   显式失能、重新使能的行为保持原有语义。

30 mm、20 mm/s 的离线 Z 直线对比：规划速度的加加速度峰值由约
`10.81 m/s³` 降至 `0.0792 m/s³`。这说明参考轨迹改进有效，**不代表真机已经顺滑**。
新增测试检查 TCP 速度曲线、节点加速度、旋转中间点以及反馈恢复时的目标连续性。
完整 ROS 环境回归结果：`47 passed`。

修正控制器后，三次 API 接管观察均保留原目标，观察窗口内关节反馈没有发生变化；
底层 C++ 驱动始终保持运行。这不能排除所有固件状态转换下的接管风险。

## 真机与摄像头证据

所有试验均记录被动 CAN 报文、目标与测量状态及 BRIO 摄像头视频；记录程序不发送
CAN 帧，运动仅经统一 API 提交。原始数据保存在本机 `.runtime/tcp-smooth/`。
相机未进行空间标定，其速度以像素/秒计算，用于独立确认实际停顿和速度脉冲。
CAN 位置反馈的 TCP 速度使用 55 ms 局部多项式导数估算。

| 同一路径的对比 | TCP 实测速度峰值 | 结果 |
| --- | ---: | --- |
| 修改前 30 mm Z 直线，目标峰值 20 mm/s | 57.1 mm/s | 卡顿，J2 终点误差超限 |
| 仅修改逆解与样条 | 58.2 mm/s | 物理卡顿仍存在 |
| 目标速度改由力矩前馈表达，关闭摩擦前馈 | 52.5 mm/s | 改善不足 |
| 目标速度摩擦前馈，比例 0.88 | 53.1 mm/s | 改善不足 |
| J4 基础 kp 从 32 降至 8 | 50.8 mm/s | 改善不足 |
| 恢复原参考增益及原摩擦补偿 | 61.4 mm/s | 卡顿仍存在 |

这些是诊断对比，起始实际跟踪误差可能不同，不能据此把小幅指标变化认定为有效修复。
摄像头光流也持续出现速度脉冲。基线圆弧虽然返回 `succeeded`，其实际速度峰值仍为
66.1 mm/s，同样不满足顺滑要求。试验性参数只用于运行时诊断，尚未写入默认 profile。

CAN 指令间隔约 5 ms，未发现足以解释上述停顿的发送间断。普通关节位置反馈与
高频电机位置反馈存在差异：J2 约 0.02 rad，J3 约 0.008 rad；两者的坐标、负载
变形和时间差仍需区分，不能把该差异直接当作已确认的零点标定值。

后续需要继续定位底层运动响应，验证不同方向、速度、姿态的直线与圆弧，并检查
运动后静止振荡、跟踪误差、停止与接管。当前结果不支持宣称该任务已经完成。

## 后续诊断：坐标差异、阻尼边界和重复空间扰动

被动读取电机位置与普通关节位置，使用有界、限速、低通的差值转换命令坐标后，
J2 静态误差从约 0.0165 rad 降至约 0.0024 rad；30 mm Z 直线往返随后通过
原有 0.01 rad 到位检查。该差值随姿态、负载变化，不能写成固定零点标定。
目前转换器仍是运行时原型，标准启动与异常恢复集成尚未完成。

J4 单轴运动中，将基础阻尼从 0.53 提高到 1.6、2.2、3.0，速度脉冲逐步减小。
但是多轴运动后 `J4 kd=3.0` 出现停车振荡，因此不能仅根据运动前静止测试选参。
J3 从 10 提高到 20 后，Z 直线的相机速度误差约减半；继续提高到 25 则在
停车后激发振荡（5 s 窗口速度 RMS 约 0.509 rad/s、电流交流 RMS 约 1.45 A）。
回退到 20 后振荡消退，随后 5 s 静止检查通过。这些参数仍需其他姿态验证，
尚未修改默认 profile。位置量化补偿、降低 J3 刚度和额外低通速度阻尼均未显示
足够改善，不能把这些试验组合直接作为最终方案。

新增相机指标将夹具的首尾位移作为比例，比较实际投影速度与五次时间律；只拟合
一个固定时间延迟。归一化 RMS 误差用于评估平顺性，不代表空间标定或路径精度。

| 30 mm Z 直线 | 相机速度归一化 RMS 误差 |
| --- | ---: |
| 原始 20 mm/s 基线 | 0.303 |
| J3 kd=20 / J4 kd=1.6，20 mm/s 正向 | 0.160 |
| 同参数，20 mm/s 反向 | 0.159 |
| 同参数，10 mm/s 正向 | 0.302 |
| 同参数，10 mm/s 反向 | 0.294 |

降低速度后波动仍明显。对不同阻尼、10/20 mm/s、正反方向的电机位置与电流
记录拟合，J3 均出现约 `omega=540 rad⁻¹` 的空间谐波，对应每约
`0.01164 rad = 0.667°` 重复一次。以电机位置作为相位，10 mm/s 正反向
拟合系数约为 `(-0.056, 0.449)` 和 `(-0.065, 0.393)` Nm（cos、sin）；
20 mm/s 正向为 `(0.029, 0.457)` Nm。这比仅观察同一速度的时间波形更支持
存在位置相关的周期性扰动，但尚不能区分其具体电磁或机械来源。

参考标定器 `fit_spatial_harmonics` 的默认搜索上限为 `120 rad⁻¹`，原模型
没有覆盖该项。正在复用其 `SpatialHarmonic` 表达做小幅残差前馈试验，原始
标定文件保持不变。当前数据只覆盖约 0.1 rad 的局部区间；需要补偿前后对比、
更多角度和路径、停车与失去上层命令时的检查，才能判断能否应用到正式后端。
