## 本次位置控制设置

默认 profile 使用 `kp=[51,64,60,64,3,3]`、
`kd=[10.375,12.12,6.32,2.12,0.3,0.08]`，关闭摩擦前馈（`friction_scale=0`），
保留原重力比例 `1` 和自适应刚度 `2`。较高增益减少位置跟踪偏差；关闭位置控制
中的摩擦前馈用于改善本次调试中的低速稳定性。覆盖仅在运行时应用，原配置、
模型和标定文件不变。`--control-profile source` 恢复原增益及原摩擦比例 `0.88`。
仿真采用同一控制设置，其拟合物理摩擦负载仍然保留。

当前完整验收使用指令速度上限 `0.05 rad/s`；早期调试曾使用 `0.08 rad/s`。
指令限速约束目标轨迹，不能作为实测速度的硬上限。完整验收结论以
[最新真机记录](hardware-acceptance.json) 的 `passed` 和各项实测数据为准。

## 真机调试发现与修复

设备为 `arm_2 / can1`，采用原重力和摩擦标定。测试只通过通用接口规划小幅运动，
早期指令速度上限设置为 0.08 rad/s。早期运行完成过 movej、关节轨迹、movel、movec、
关节/TCP/Twist 实时流、超时及取消；随后更严格的复验发现终点偏差与退出问题。
完整验收结果保存在 [硬件记录](hardware-acceptance.json)。中间一轮使用 J4
`kp=32, kd=1.5` 的复验在返回运动时出现 0.01033 rad 终点误差，失败记录保留于
[调参前记录](hardware-tuning-before-final.json)；最终 profile 提高了 J4 增益并重跑全部项目。

原柔顺增益下 J4 有约 0.025 rad 静态误差。独立位置控制 profile 调整 J1/J4
增益后，曾完整完成一次 0.01 rad 终点容差验收；但实测短时速度高于指令上限，
并在继续复验时观察到异常固件模式与未预期姿态变化。因此这次成功不作为最终
合格依据。指令限速不能保证真实关节速度绝不超过该数值。

最初的 API 退出实现先切固件关节模式再发送当前位置，存在旧目标被采用的风险。
该实现已移除。现在保持 MIT 模式：未修改的驱动由独立 ROS 固定目标进程接管，
带补丁的驱动自行保留超时目标；API 在接管确认前继续发布，不终止底层驱动。
真实的 API→保持进程→API 交回保留了相同目标，前后最大关节变化 0.00063 rad：
[接管记录](hold-handoff-verification.json)。这验证发布接管，不等于固件当前就绪。

## 示教状态原因与恢复进展（2026-11-26）

恢复前，原始 `0x2A1` 状态持续在 `ctrl_mode=2`、`teach_status=1/2` 间切换；总线上没有
观察到开始示教指令。结束示教、Follower 配置及终止执行探测没有恢复稳定控制。
上游 `mit_ready` 可能保留旧值，所以新适配层直接检查原始状态，要求连续 100 ms
确认 CAN/MIT 模式，才置 `command_ready=true`。当时不满足，新运动被拒绝。

用户已确认实体按钮松开、没有卡住。原驱动暂停 0.4 s、以相同六帧 MIT 支撑和
10 Hz 模式请求隔离重试期间，固件仍处于示教状态，且未观察到关节移动。
因此不能把原驱动的结束示教重试循环认定为唯一根因。vendor 已修复独立确认的
旧 `mit_ready` 标志问题，当时原工作空间与运行驱动没有替换；后续有计划启动了
仓库内的修订驱动，原工作空间文件仍保持不变。

随后一次 SDK `reset()` 探测发生了延迟重初始化和实际移动，用户确认当前稳定、
没有碰撞。这次风险判断不充分。进一步查到[厂商明确说明](https://github.com/agilexrobotics/piper_sdk/issues/66#issuecomment-3162642963)
该指令会关闭电机，持续 MIT 支撑不能消除这一行为。不能把复位瞬间的零反馈当成
真实运动量，也不能将短时隔离期间的零运动当作整个复位安全的证据。

之后两轮独立关节使能仍未恢复控制权。[完整摘要](hardware-recovery-2026-11-26.json)
保留前后状态、指令、首个异常与现场确认。当时原驱动继续固定目标输出，不推进
轨迹，并在进一步恢复前请求现场物理支撑。

随后用户确认示教按钮绿灯常亮，短按一次使灯熄灭；再按官方手册先切待机、再切
CAN 控制后，已恢复外部控制。本次持续示教状态的已确认原因是**录制模式未退出**：
按钮虽已松开，录制仍开启，固件因此重复报告 `teach_status=1`。松开瞬时按钮与
关闭录制是两个不同状态，之前仅确认“按钮松开”不足以排除示教录制。

[官方手册 PDF 第 25–26 页](https://cdn.shopify.com/s/files/1/0551/0630/6141/files/PIPER_X_USER_MANUAL.pdf?v=1791861496)
明确规定绿灯常亮为录制、灯灭为结束，短按切换，双击回放；恢复命令控制需先确保
灯灭，再待机，再 CAN。Dashboard 已补充针对录制状态的具体提示，不自动复位。
